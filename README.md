# 💰 Personal Expense Tracker

A simple and user-friendly web application to record, manage, and track daily expenses. This project uses Firebase Firestore to store expense records in real time and Firebase Hosting for deployment.

## 🚀 Features

* ➕ Add new expenses
* 📝 Enter expense title and amount
* 📂 Select expense categories:

  * Food
  * Travel
  * Shopping
  * Bills
  * Other
* 📅 Select expense date
* ☁️ Store expenses in Firebase Firestore
* 📋 Display saved expenses
* 🌐 Firebase Hosting deployment

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Firebase Firestore
* Firebase Hosting

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd Personal-Expense-Tracker
```

### 3. Firebase Configuration

* Create a Firebase project.
* Enable Cloud Firestore.
* Register a Web App in Firebase.
* Add your Firebase configuration to the project.

### 4. Run the Project

Open `public/index.html` in your browser or use the VS Code Live Server extension.

## 🔥 Firebase Services

* **Cloud Firestore:** Stores and retrieves expense records.
* **Firebase Hosting:** Hosts the web application online.
